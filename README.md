# Laced Notes

A local-first songwriting and idea studio. This V1 build uses no account, cloud sync, audio or external AI service. Data is stored in the browser on your own device.

## Publish with GitHub Pages

In this repository, select **Settings → Pages → Build and deployment: Deploy from a branch**, select **main** and **/(root)**, and save. The site URL should be:

https://lacespun.github.io/LACED-notes/

Open the link in Safari on iPad, then **Share → Add to Home Screen**. Project content stays in the Safari/PWA browser storage of that device, not in the public GitHub repository. Use **Operations → Export backup** regularly and retain the JSON file somewhere safe. Clearing browser storage can erase locally saved content.
